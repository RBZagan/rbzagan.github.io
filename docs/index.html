How this site is built

The site is static, self-contained, and has no build step. Every page is a plain HTML file, styled by three layered stylesheets that resolve a single set of design tokens.

There is no JavaScript framework and no webfont. The only script is a small loader that fetches the shared header and footer so navigation lives in one file and cannot drift between pages.
