Roblox package

lobby

The lobby for the Minigame universe — a Roblox package written in Luau and developed as a source tree with Rojo, so the package is committed as reviewable files rather than as a place file.

What it is for

A lobby is where a player arrives before they play. It is the first thing the universe loads and the last thing they see before a match, so it carries the session entry point, the navigation between game modes, and the presentation layer that all of them share.

It is a package rather than a place, so the game modes it fronts can depend on it without duplicating it.

Design commitments

  • Server-authoritative. The client asks; the server decides. No client-supplied result is ever trusted.
  • Strictly typed. Every part of the package declares its types rather than leaving them to be inferred.
  • Source, not place. Rojo keeps the instance tree derived from files, so every change is reviewable.
  • No runtime dependencies. The package is self-contained apart from Roblox itself.
